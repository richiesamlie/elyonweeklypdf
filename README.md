# Elyon Weekly Program PDF Hub — PWA

Progressive Web App (PWA) wrapper for the Elyon Primary Weekly Program PDF Hub. Allows teachers to install the app on their phone or desktop for quick access.

## Features

- **Installable** — Add to Home Screen on mobile, install on desktop
- **PDF Exporter** — Export weekly program PDFs for single or multiple classes
- **Program Editor** — Edit subject materials and notes directly from the browser
- **Secure** — Only accessible by @elyon.sch.id Google accounts

## Access

**Web:** [https://richiesamlie.github.io/elyonweeklypdf/](https://richiesamlie.github.io/elyonweeklypdf/)

Requires a valid @elyon.sch.id Google account.

## How to Install

### Mobile (Android/iOS)
1. Open the link above in Chrome or Safari
2. Tap **"Install"** when the banner appears, or use browser menu → **"Add to Home Screen"**

### Desktop (Chrome)
1. Open the link above in Chrome
2. Click the install icon in the address bar, or use **⋮ Menu** → **"Install app..."**

## Tech Stack

- [Google Apps Script](https://script.google.com) — Backend & data storage
- [Google Sheets](https://sheets.google.com) — Source of truth for weekly schedules
- [Google Drive](https://drive.google.com) — File storage
- Static HTML/CSS/JS — PWA wrapper (this repo)
