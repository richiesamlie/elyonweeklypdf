# Elyon Weekly Program PDF Hub — PWA

Progressive Web App wrapper for the Elyon Primary Weekly Program PDF Hub. Allows teachers to install the app on their phone or desktop for quick access.

## Access

**[Open App](https://richiesamlie.github.io/elyonweeklypdf/)**

Requires a valid @elyon.sch.id Google account.

## How to Install

### Mobile (Android/iOS)
1. Open the link above in Chrome or Safari
2. Tap **"Install"** when the banner appears

### Desktop (Chrome)
1. Open the link above in Chrome
2. Click the install icon in the address bar

## Files

| File | Purpose |
|------|---------|
| `index.html` | Wrapper that embeds the GAS app via iframe |
| `manifest.json` | PWA manifest |
| `sw.js` | Service worker for installability |
| `icon.svg` | App icon |
