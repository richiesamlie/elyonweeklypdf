📌 Important Note
This web app does NOT replace your Google Sheets. Your spreadsheets remain the original source of truth. The app simply reads from and writes to your Google Sheets directly to make exporting PDFs and editing weekly schedules faster and easier!

📄 How to Export PDFs

  1. Select a Grade Level chip (P1, P2, P3, P4, P5, P6).
  2. Select the Week Tab from the dropdown menu (e.g. 03-07 Aug).
  3. Check the boxes for the classes you want to export (e.g. 5A, 5B).
  4. Click ⚡ Export Selected Classes.
  5. Click ⬇ Download Package (single PDF or ZIP package).

✏️ How to Edit Subject Materials

  1. Click the ✏️ Program Editor tab at the top.
  2. Select your Grade chip (e.g. P5) and Class chip (e.g. 5C).
  3. Select the Week Tab.
  4. Type or edit subject materials and notes in the text boxes.
  5. Click 💾 Save Changes to Google Sheet.

✨ How to Create a New Week Tab

  1. In Program Editor mode, click ➕ New Week Tab.
  2. Pick any date on the calendar picker for that school week.
  3. The app automatically calculates Monday–Friday and formats tab name (e.g. 03-07 Aug).
  4. Select the template tab to copy formatting from.
  5. Click Create Tab (past tabs remain 100% preserved).

🗑️ How to Delete a Mistaken Tab

  1. In Program Editor mode, select the week tab to remove.
  2. Click 🗑️ Delete Tab.
  3. Confirm with Yes, Delete Tab.
